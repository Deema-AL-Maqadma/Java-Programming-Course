# Java Programming – Course Repository

This repository contains all materials, assignments, projects, and exams from my **Java programming courses** at university.  
It combines **theoretical foundations** with **practical implementations** across multiple courses: Fundamentals, Object-Oriented Programming (OOP), Data Structures, Advanced Algorithms, and Final Projects.

---

## 📚 Course Content
During these courses I studied and applied the following topics:

- **Fundamentals of Programming (Java Basics)**  
  Variables, loops, conditions, arrays, and introductory projects.  
  Final project included in **MyProjects** folder.

- **Object-Oriented Programming (OOP)**  
  Classes, objects, encapsulation, inheritance, polymorphism, aggregation, and ArrayLists.  
  Final projects combining multiple OOP concepts.

- **Data Structures (DS)**  
  Implementation of stacks, queues, linked lists, bags, and priority queues.  
  Projects included practical applications like balanced parentheses and treasure chest management.

- **Advanced Algorithms**  
  Brute force, divide and conquer, transform and conquer, dynamic programming, Gaussian elimination, and more.  
  Implemented fully in Java using NetBeans.

---

## 📂 Repository Structure
The repository is organized as follows:

- **BasicsOfProgramming/**  
  Contains all introductory Java exercises and projects.  

- **OOP/**  
  Includes assignments, labs, and final projects applying OOP concepts.  

- **DataStructure/**  
  Contains implementations of stacks, queues, linked lists, and other data structures.  

- **AdvancedAlgorithm/**  
  Includes advanced algorithm implementations and related projects.  

- **MyProjects/**  
  Final projects combining multiple concepts from different courses.
